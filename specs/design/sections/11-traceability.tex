\section{Requirement Traceability}
\label{sec:traceability}

Every requirement of the functional specification is listed below with the tests
that check it, cited by name so they can be run and read.  A citation without a
file extension names a Go test function (\code{internal/\ldots\_test.go} or
\code{cmd/fsb/\ldots\_test.go}); \code{e2e:} names an end-to-end browser test by its
title in \code{e2e/suite.mjs}; \code{web:} names a Node test file under
\code{web/src/lib/}.  Where a requirement is not checked by an automated test, that
is stated plainly rather than left to be inferred from an empty cell; Section~
\ref{sec:untested} collects the reasons.  This table was produced by reading the
requirements against the test suite as it stands on the commit this document was
built from; it is not generated, and it should be re-checked whenever a requirement
or a test changes.
