\section{Decisions and Alternatives}
\label{sec:decisions}

Each row is a decision that shaped the design, with what else was possible and why it was not
chosen.

\begin{center}
\small
\begin{longtable}{@{}p{0.20\linewidth}p{0.20\linewidth}p{0.52\linewidth}@{}}
\toprule
Decision & Rejected & Why \\
\midrule
\endhead
Write from scratch in Go with an embedded Svelte front end & Fork an existing multi-user file manager & The existing one is built around a jailed root, configuration in its own UI, and create, rename and delete. The security model here (whole home, read only, two-tier rules) is different in kind, and a fork would carry code paths that must not exist. \\
Two tiers: hide and deny & One list & Hiding clutter is cosmetic and must not be a security control; blocking must be absolute, not overridable, and load only from the global file so that a folder cannot relax it. Deny wins over ignore. \\
Deny loads only from the global file & Per-folder deny files & A per-folder file could be planted in the tree being browsed to weaken protection. \\
Core rules built in and active by default & Ship them commented out, with a warning & A tool that exposes \code{\~{}/.ssh} until configured is unsafe by default. The warning now covers only the case where the user weakened them. \\
Bind loopback only, not configurable & A flag for other interfaces & There is no safe way to serve the whole home folder to a network, so the option is not offered. \\
Single-use launch token, then a cookie & A permanent token in the URL & A token left in history or a shell must be useless. \\
Path prefix scoping the cookie & A plain cookie; a custom header on every request & Browsers cannot scope cookies by port. A header cannot accompany images, frames, PDFs and downloads. A random path scopes the cookie exactly. \\
Identity for hard links, from a background index & A hash of contents; a synchronous walk & A hash flags harmless copies, reads every candidate, and answers a different question. A synchronous walk did not finish in four seconds on a real home folder and would stall a request. Refusing until known keeps it safe meanwhile. \\
Roots decided by identity & Comparing folded text & Right on a case-insensitive volume, wrong on a case-sensitive one. \\
Full case folding, from \code{x/text}, applied to rules & \code{ToLower} & The volume uses full folding; simple folding made some spellings of a denied name invisible to the rules. \\
Refuse a file whose kind the bytes do not confirm & Trust extensions & An extension is chosen by whoever named the file. \\
Markdown in a sandboxed frame, sanitized, with a hash-pinned policy & Render in the page with a sanitizer only & One layer failing must not compromise the session; the frame has no origin, no network and one fixed script. \\
PDF in the browser's viewer in a frame with narrow framing headers & Bundle a PDF library; sandbox the frame & A library is large and a second parser to defend; a sandboxed frame is refused by browsers. \\
Stream listings as newline-delimited JSON & Pagination & The client sorts, which needs all entries; streaming paints early and keeps them all. \\
Sort in the browser & Sort on the server & The sort key and options change often; the total-order comparison is a pure, testable function. \\
Pure modules tested with Node's runner & A browser test for every function & Fast, dependency-free, and the laws are stated on them. \\
Commit the compiled front end & Build it in the Go build & Building the binary must need no Node. CI checks that the committed output is current. \\
Deny checks over-match; allow checks decide by identity & One equality for both & The two directions fail differently: over-matching a deny only blocks more, over-matching an allow serves the wrong folder. \\
Serve a multi-name file only when every name is accounted for, now & Allow until known; allow a file the walk cannot see after a second walk; trust a file whose change time is old & The window in which a hard link to a secret is served must be zero, at the cost of some unavailability. A file's own change time does not move when a folder holding one of its names is renamed, and a fail-open rule for a file the walk could not see let a link through; each was tried and broken by a review. \\
A listing or search reuses a hard-link verdict for one second & Re-verify on every entry; remember for the whole response & Re-verifying costs a look at every recorded name per entry (the square of the link count for a store with thousands of names). Remembering for the whole response lets a rename that leaves the count unchanged stay invisible for as long as the response runs. One second bounds the staleness; opening a file never uses the memo. \\
Cancel copying and listing cooperatively & Abandon the work and release the slot; promise a hard deadline & A context check cannot interrupt a read the file system is holding up. Abandoning the work would release the slot while it still ran, so the limit would be a fiction. A hard limit needs work that can be killed and cleaned up, which this version does not have; the limits are described as cooperative. \\
Read a zip's directory ourselves, record by record & The standard library's reader behind a count check & The library builds the whole directory in memory before any count of ours applies, and a check on a 16-bit field cannot see a zip64 count. A limit has to be applied while reading. \\
End every stream with a done line & Treat the end of the connection as the end & A dropped connection is indistinguishable from a short folder; the line says how it ended, and the client treats its absence as an error. \\
Hand-written manual page in roff & Generate it from Markdown & No build dependency, and the format users expect. \\
Remember the last port; \code{--port} for one run only & A preferences file or endpoint on the server; a cookie; \code{--port} that is remembered & A server-side store needs a write path, breaking read-only by construction, and would be one file shared by concurrent instances. Cookies are not scoped by port, so one would either reset like local storage or reopen the cross-server leak the path prefix closes. A remembered \code{--port} would turn a one-off workaround into a permanent move to an empty set of preferences. \\
Fail, naming the holder, when the remembered port is taken & Silently pick another port & A silent move looks exactly like losing every preference, with nothing to say why. \\
Background mode by re-executing in a new session, with a handoff pipe & Tell users to run \code{fsb \&}; daemonize with a double fork & Job control is unfamiliar to many users and ties fsb to the terminal. Go cannot fork safely; a re-executed child that reports its own startup over a pipe lets the parent show the real error and leave nothing running. \\
Identify a running fsb by owner, executable file and start time & By the command name \code{ps} shows & On macOS that name is the process's \code{argv[0]}, which any program can set (found by the independent review). \\
Quick Look draws a private copy & Hand Quick Look the user's path, re-checking afterwards & Quick Look resolves Finder aliases that the guard cannot see, so a path that passed every check could still lead it to a denied file (found by the independent review). A copy made from a verified descriptor has nothing to follow and cannot be swapped. \\
Quick Look chosen by extension & Sniff the bytes, as other previews do & Quick Look decides what a document is, and a package has no bytes of its own; the copy makes the name harmless. \\
Leave denied parts out of a package's copy & Refuse the whole package & Refusing answered differently for a package with a hidden part than for a clean one, revealing what a listing hides. \\
One set of core rules on every system & Rules chosen by the running system & A copy of one system's home folder is often browsed from the other (a backup, a mounted disk), and a rule for a folder that does not exist costs nothing; one list is also one list to review. The cost is a startup warning, for users with a deny file, each time the list grows. \\
Flatpak rules match any application ID & List the usual IDs & Repackaged browsers (ungoogled-chromium, say) use their own IDs but the same folder names under \code{config}; a wildcard on the ID with a fixed folder name stays narrow. Identity protection of hard links (\code{CredentialLocations}) still needs literal paths, so it names the usual IDs. \\
Read \code{/proc} on Linux to find a running fsb & Require \code{ps} and \code{lsof}; ship fallbacks for BusyBox & Minimal systems lack both and BusyBox's \code{ps} lacks the options, so \code{--stop} said no \texttt{fsb} was running while one served; \code{/proc} is always there, and \texttt{fsb} already read \code{/proc/PID/exe}. \\
Escape stray bytes as NUL and two hex digits, decoded by the client & Send names as base64 or byte arrays; U+FFFD; Python's lone-surrogate escape; decode on the server & An extra field would change every client path; U+FFFD loses the name; a lone surrogate makes \code{encodeURIComponent} throw. NUL cannot occur in a name, so the escape is unambiguous, and a client that turns it back into bytes keeps every decoder out of the security core. \\
Pin the \code{/proc} layers with a test, not new rules & Deny \code{/proc/*/environ} and the like & Nothing leaked: the files report size 0 and are NUL-separated. New core rules would have warned every user with a deny file, a fourth time in one day, for paths already safe; a test that fails if either layer goes is the proportionate guard. \\
Record a start ID, not the start time as text, in the PID file & Keep the text and compare in UTC; store the time with its zone & Text in the local zone broke \code{--stop} under another \code{TZ} (finding 38). On Linux the kernel's start in ticks since boot is exact and moves with neither the zone nor the clock; on macOS \code{ps} gives only local text, so it is parsed in the zone it was printed in. Old files stay readable. \\
Attempt Quick Look only on macOS & Run \code{qlmanage} wherever it is found & There is no Quick Look elsewhere; a program of that name on \code{PATH} would be some other program, given a copy of the document, after a copy of up to 256~MB. \\
